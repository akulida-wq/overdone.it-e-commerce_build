в app.vue. Inter удалён полностью. TODO(FONT) закрыт.

## 3. «What we handle» — пункты исчезали при hover ✅
Баг: reveal() очищал inline opacity (clearProps), а Vue при hover-ре-рендере
затирал JS-класс .is-revealed → CSS-прескрытие возвращалось. Фикс в
useScrollMotion.reveal(): opacity остаётся inline, очищается только transform.
Затрагивало и hover-связку блоков сравнения.
