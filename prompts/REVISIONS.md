# REVISIONS — схема правок после сборки (как на Paparazzi)

Когда страница собрана и появились правки:

1. Делаешь нумерованные скриншоты `r{N}-s{M}` (например r1-s1, r1-s2…) и текстовый список правок, где ссылаешься на «фото M»
2. Кидаешь это мне в чат (или кладёшь скрины в папку проекта, если не влезают, — тогда скажи, и промт будет начинаться с «найди и посмотри скриншоты»)
3. Я готовлю:
   - `CHANGES_R{N}.md` — детальная спека правок с кодом и таблицей «какие файлы меняем»
   - `PROMPT_R{N}.md` — 4–8 промтов для Claude Code, каждый заканчивается `npm run build` + проверкой, плюс секция «если что-то пошло не так»
4. Прогоняешь промты по порядку, спорные места возвращаешь следующим кругом

Правила для правок те же, что в CLAUDE.md: цвета через var(--color-*), размеры токенами, тексты только через локали (правка текста = правка en.json и ua.json одновременно), reduced-motion не ломать. Если правка визуально значимая — в CHANGES прошу Claude Code замерить «до/после» (размеры, отступы), чтобы правки не терялись.
