Прочитай CLAUDE.md, docs/DESIGN.md §6 и docs/PAGE_SPEC.md §5–§6. Этап 3 из 7. Сделай:

1. `SectionLayers.vue` — флагманская scroll-секция по спеке §5. Порядок работы:
   а) Сначала собери статичную финальную сцену: SVG-мокап витрины магазина (шапка, карточка товара, кнопка) + 6 слоёв-плоскостей под ним в CSS 3D перспективе (rotateX), mono-подписи из `layers.*`, соединительные линии. Добейся, чтобы статично это выглядело аккуратно на 1440 и 768
   б) Потом оберни в GSAP timeline с pin+scrub по фазам из спеки: цельный мокап → наклон и разъезд слоёв со stagger → смена текста слева → красная подсветка связей
   в) Sticky-текст слева переключается по тем же фазам (fade 250ms)
   г) Mobile и reduced-motion: без pin — сразу статичная изометрия + весь текст под ней. Реализуй как отдельную ветку шаблона по media/motion флагу, не пытайся «чинить» pin на мобильном
2. `SectionIncluded.vue` по §6: вступление, сетка 11 чипов с SVG-иконками (нарисуй простые stroke 1.5px иконки одним стилем: магазин, CRM, карта оплаты, ценник, склад, заказ, грузовик, уведомление, график, шестерёнка, интеграция-звенья), hover, reveal stagger, финальная строка
3. Подключи в index.vue

Закончи: `npm run build`. Проверь: pin не оставляет «дыр» после себя, при resize ScrollTrigger.refresh() отрабатывает, на 390px секция читабельна без pin, обе локали, консоль чистая, скролл остаётся плавным (transform-only, will-change во время анимации).

Если что-то пошло не так: если слои мерцают — добавь backface-visibility hidden и translateZ(0); если pin прыгает — проверь, что у секции нет margin-collapse и pinSpacing включён; если фазы текста рассинхронены — привяжи их к прогрессу того же timeline, а не к отдельным триггерам.
