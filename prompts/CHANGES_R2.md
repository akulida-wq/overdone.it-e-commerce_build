## R2.1 Лого + hover-анимация

Фото: нет. Ассет: файл логотипа лежит в папке проекта (найди `logo*` / `*.svg` вне assets).
- Перенеси файл в assets, подключи в PHeader (и футер, если там тот же знак) как inline-SVG компонент `LogoOverdone.vue`

## R2.2 Секция What we handle (SectionScope)

Фото: `r2-s1` (текущее состояние), `r2-s2` (целевой пример). Реф появления: https://thewatch.60fps.fr
- Строка: **слева цифра** 01–07 (как сейчас, но выровнять по горизонтальной оси центра заголовка), рядом заголовок; **справа `+`**; **центр строки пустой** в базовом состоянии
- Hover строки: по центру появляется описание (fade + лёгкий slide-up 12px, 250ms), `+` поворачивается в `×` (45°, та же длительность), цифра краснеет
- КРИТИЧНО — hover при скролле: активная строка определяется положением курсора, даже если мышь неподвижна, а страница скроллится под ней. CSS `:hover` этого не умеет. Реализация: хранить mouseX/mouseY (mousemove), на каждый тик скролла Lenis (throttle через rAF) делать `document.elementFromPoint(mouseX, mouseY)?.closest('.scope-row')` и переключать класс `.is-active`. Никакой логики на CSS :hover — только класс
- Появление секции как на thewatch.60fps.fr: строки появляются последовательно снизу-вверх из-под маски (clip-path inset снизу → 0) со stagger ~80ms, плавно и «дорого» (duration ~0.9s, ease power3.out), заголовок секции — раньше строк
- Touch-устройства: тап = toggle описания (как сейчас)

## R2.3 Ползунки (PSlider) — калькулятор и форма

Фото: `r2-s3`. Сделать похоже, но проще и минималистичнее, под наш стиль:
- Трек тонкий (2px, `--color-border-strong`), заполненная часть до ручки — белая или красная (в калькуляторе красная, в форме белая — проверь визуально, выбери один вариант и применяй везде одинаково)
- Ручка: круг 18–20px, фон bg, бордер 1.5px белый; при drag/focus — бордер красный + лёгкий glow; курсор grab/grabbing
- Текущее значение ступени — подпись над ручкой (small, следует за ручкой), крайние подписи ступеней под треком muted mono
- Движение ручки к ступени — с лёгкой пружинкой (snap с ease ~200ms), без дёрганья; drag работает мышью и тачем, стрелки клавиатуры — по ступеням
- Это по-прежнему один компонент PSlider для калькулятора и формы

## R2.4 Секция The website is only the visible part (SectionLayers) — переработка

Фото: `r2-s4` (текущее), `r2-s5`, `r2-s6`, `r2-s7` (реф до открытия / во время / после, с подписями). Реф: https://neoconda.com — сделать максимально похоже, только под наш смысл.
- Новая композиция: **заголовок слева, описание секции справа напротив по горизонтали** (две колонки сверху секции); **вектор — крупнее и по центру** под ними, сцена занимает основную ширину
- Детализация: верхний слой — узнаваемый мокап витрины магазина; каждый нижний слой несёт СВОЮ мини-графику по смыслу подписи (CRM — карточки заказов/канбан; Оплата — карта и чек; Склад — ряды ячеек/коробки; Доставка — маршрут с точками; Повідомлення — пузыри сообщений; Аналітика — мини-графики). Стиль графики слоёв: тонкий stroke 1.5px + заливки surface, единый с остальной страницей
- Анимация раскрытия — как на neoconda (фазы по фото s5→s6→s7): closed-состояние (слои сложены в один объект) → по scrub слои разъезжаются вертикально в изометрии с лёгким rotate → в конце все слои разведены и видны все подписи
- Подписи: расположение лесенкой со сменой сторон — 1-я сверху слева, 2-я ниже справа, 3-я ещё ниже слева и т.д., с тонкими линиями-выносками к своим слоям. Анимация появления подписи — просто opacity 0→1 (по мере раскрытия своего слоя)
- Mobile/reduced-motion: конечное раскрытое состояние статично, подписи списком под сценой
