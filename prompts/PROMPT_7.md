Прочитай CLAUDE.md и DESIGN.md §6. Финальный этап 7 из 7 — полировка всей страницы. Сделай по порядку:

1. Лёгкий прелоадер: логотип Overdone + короткая анимация появления (макс 1.2s, показывается один раз за сессию, скрывается сам; reduced-motion — без него). Никаких процентов-счётчиков
2. Пройди страницу сверху вниз и выровняй моушен: единые длительности/изинги по DESIGN §6, reveal-ы не конфликтуют с pin-секциями, ничего не анимируется дважды, скролл-подпрыгиваний нет
3. Полный проход reduced-motion: страница обязана быть полной и красивой статично
4. Доступность: последовательность заголовков h1→h2→h3, focus-visible стили на всех интерактивах, aria-label на иконочных кнопках, контраст текста ≥4.5:1 (muted #7a7a7a на #070707 проходит только для крупного текста — проверь мелкие подписи, при провале поднимай до #a7a7a7), skip-link к контенту
5. Производительность: lazy-загрузка изображений ниже сгиба, width/height или aspect-ratio у всех img (CLS < 0.1), preload display-шрифта, font-display: swap, отключение will-change после анимаций. Прогони Lighthouse (mobile): цель Performance ≥ 85, Accessibility ≥ 95 — приложи до/после
6. SEO/меты: title, description (возьми лид hero), og-теги в стиле главной, lang меняется с локалью, favicon с главной
7. Создай `HANDOFF.md` в корне: как перенести страницу в основной проект overdone.it (список файлов, зависимости, что заменить: TODO(FONT) SF Pro с прода, TODO(ASSET) hero-3d и скрины партнёров, TODO(API) endpoint формы, TODO(FAKE) формула калькулятора), и как добавить нового партнёра (объект в partners)

Закончи: `npm run build`, полный ручной проход обеих локалей на 1440/1024/768/390, консоль чистая. Выпиши списком всё, что осталось как TODO.
