## Общие принципы моушена

- Библиотеки: GSAP + ScrollTrigger, Lenis. Изинги «премиальные»: длинные (0.8–1.2s) power3.out / expo.out на появлениях, микроховеры 200–300ms
- Появление секций по умолчанию: заголовок построчно из-под маски (clip-path), затем контент fade+up 24px со stagger — как на trionn/produx. Один раз, без реверса
- Каждая pin-секция и каждый луп обязаны иметь reduced-motion фолбэк (статичное финальное состояние) и мобильный вариант без pin
- Всё transform/opacity-only; will-change точечно

## Секции (нумерация заказчика)

### S0. Прелоадер
- Элементы: по центру красная 3D-фигура (экспортируй из макета/hero как webp с прозрачностью), проценты 0→100, тонкая полоска прогресса внизу экрана
- Появление элементов лоадера тоже плавное (fade+up, ~400ms)
- Фигура медленно вращается: для плоского webp честно работает только ось Z —媚 медленный rotateZ (~14s/оборот, linear, бесшовный) + едва заметное «дыхание» scale 1↔1.015. rotateY/X на плоской картинке выглядит фальшиво — не делать. (Опция на будущее: настоящий 3D — секвенция кадров или GLB, TODO(ASSET-3D))
- Проценты привязаны к реальной загрузке (fonts.ready + hero-ассеты), но минимальная длительность 1.2s и максимальная 2.5s (дальше — доводим до 100 принудительно); выход: проценты и полоска доезжают до конца, шторка/фейд открывает страницу, hero начинает своё появление только после выхода лоадера
- Показывается раз за сессию (sessionStorage), reduced-motion — без лоадера

### S1. Hero
- Статика по макету (заголовок «Your Online Sales System With No Upfront Fee», кнопки, mono-подпись)
- Появление: премиальный каскад — заголовок построчно из-под маски, затем суб/кнопки/подпись fade+up stagger 80ms, фигура — fade+scale 1.04→1
- Фигура (idle): бесконечный медленный float вверх-вниз ±6px (sine.inOut, ~6s цикл)
- Параллакс за мышью: фигура плавно (lerp 0.06–0.08) смещается ЗА курсором на небольшую амплитуду (±14px X, ±10px Y от центра вьюпорта); тач — только float
- (Опция v-next: реальное вращение фигуры — нужен 3D-ассет, TODO(ASSET-3D); сейчас не делать)

### S2. Проекты «Businesses growing with us»
- Анимация 1в1 как trionn.com секция «selected works & explorations» (референс — сайт, фото нет): карточки-обложки появляются при скролле с подъёмом и лёгким clip-reveal; hover — картинка внутри рамки медленно масштабируется (scale 1→1.06, ~0.8s), заголовок/стрелка сдвигаются, курсор-лейбл если есть в макете
- Карточки: Paparazzi (→ /projects/paparazzi, страница остаётся из прошлой версии до отдельного редизайна) и «Your product could be next» (→ #contact)

### S3. «The website is only the visible part» — pin со слоями
- Референс: neoconda.com «Precision in every component», фото `refs/f1.png`. В макете два стейта: карточка сайта целиком (фронтально) и полностью разложенные слои с подписями
- Механика: доскроллили до секции → pin. Фаза 1: видна одна карточка сайта спереди. По скроллу (scrub) карточка наклоняется в перспективу и плавно разделяется на слои (разъезд по вертикали со stagger, как выезжают платы на референсе), подписи-выноски проявляются opacity 0→1 каждая при раскрытии своего слоя. Полностью раскрылось (= второй стейт макета) → pin отпускает, скролл идёт дальше
- Скролл назад отматывает раскрытие (двунаправленный scrub)
- Длина pin ~2–2.5 вьюпорта. Mobile/reduced-motion: статичный разложенный стейт

### S4. Карточки-компоненты системы
- Анимация 1в1 как produx.design секция отзывов «Trusted partners», фото `refs/f2.png`: карточки в раскладке со сдвигом по вертикали, последовательная автоактивация с прогресс-полосой, при hover — активация переходит на карточку под курсором, пауза автопрогона
- Вне вьюпорта автопрогон стоит (IntersectionObserver)
- Векторы в карточках заменить на подходящие по смыслу каждому пункту; стиль — как в макете / `refs/SVG_icon_example.svg` (тонкий stroke, острые углы)

### S5. Statement «Development is usually paid upfront…»
- Появление текста как trionn.com секция about, фото `refs/f3.png`: крупный текст разбит на слова, слова проявляются из muted (#7a7a7a) в белый последовательно по scrub скролла; акцентная фраза в красный. У скринридера текст единый (aria-label на контейнере)
- Мелкие серые подписи по краям (как у trionn) — новые тексты:
  - Левая, EN: «No fixed budgets. No prepayment. An agreed percentage of sales — after launch.» / UA: «Без фіксованих бюджетів і передоплат. Погоджений відсоток від продажів — після запуску.»
  - Правая, EN: «Our income starts together with your sales. That keeps both sides focused on one thing — growth.» / UA: «Наш дохід починається разом із вашими продажами. Тому обидві сторони зосереджені на одному — на зростанні.»
  - Появление подписей — fade+up после того, как statement прокручен наполовину
- Большое серое лого Overdone на фоне: медленное вращение rotateZ (~40s/оборот, linear; для плоского знака Z — единственная честная ось) + лёгкий параллакс за мышью (lerp, ±8px). Лого — SVG, opacity по макету

### S6. «Two ways to build»
- Появление: заголовок из-под маски, карточки подъезжают fade+up со stagger 120ms; hover карточек/кнопок по макету
- Заменить иконки минусов/галочек на смысловые иконки каждого пункта. Набор: Material Symbols Light (Google, тонкие, острые углы; лицензия Apache 2.0 — ок). Маппинг: Payment → `payments`/`receipt_long`; Risk → `shield`/`warning` (off-вариант у классики); Motivation → `target`/`trending_up`; Post-launch → `build`/`autorenew`; Decisions → `alt_route`/`done_all`. В партнёрской карточке иконки красные, в классической — muted. Подбери конкретные глифы по смыслу каждой строки, выдержи один вес
- SVG иконок — инлайн-компонентами (не шрифт)

### S7. «What we handle» — строки-аккордеон
- В макете есть базовый стейт и стейт при наведении — повторить точно

### S8. «How the partnership begins» — pin с вращением карточек
- Референс: daoism.systems секция партнёров, фото `refs/f4.png`; в макете есть промежуточные состояния — сверяйся с ними
- Механика: секция pin. По scrub карточки шагов «вращаются по кругу»: активная уходит (сдвиг+scale down+blur+fade), следующая выезжает на её место из стопки; текст справа меняется синхронно с активной карточкой (fade 250ms). 5 шагов = 5 отрезков прогресса, скролл назад отматывает. После последнего — pin отпускает
- Hover активной карточки — как на референсе (лёгкий подъём/подсветка)
- SVG-иконки на карточках — по смыслу заголовка+описания шага, стиль как в макете
- Тексты шагов — из локалей прошлой версии (steps.*)
- Mobile/reduced-motion: вертикальный список карточек с текстами

### S9. Калькулятор «Terms are tailored to each business»
