# PAGE_SPEC — спецификация страницы E-commerce Partnership

Порядок секций сверху вниз. Тексты: CONTENT_SOURCE.md (базовые секции) + CONTENT_ADDITIONS.md (новые блоки, форма, UI-строки). Ключи локалей указаны у секций.

Общее: каждая секция — отдельный компонент `sections/Section*.vue`, обёрнутый в контейнер; eyebrow + заголовок через общие компоненты; появление контента — стандартный reveal (DESIGN §6), если не указано иное.

## §0. Языковая модалка (LangModal)

- Показ: первый визит, нет `localStorage('od_lang')`. Задержка 600ms после загрузки
- Вид: небольшая центрированная карточка (`--color-surface`, radius lg, бордер), затемнение фона 50%
- Контент: `lang_modal.title`, две кнопки-строки «Українська» / «English» (secondary, полная ширина), под ними `lang_modal.note` (small, muted)
- Выбор → сохранить, закрыть (fade+scale 200ms). Закрытие по крестику/фону → остаётся en, тоже сохранить, больше не показывать
- Esc закрывает; фокус-трап внутри модалки; `role="dialog"` `aria-modal`

## §1. Header (PHeader)

- Как на главной: слева лого Overdone (SVG; hover — «оживление»: лёгкий поворот/морф знака, 300ms — референс mesh3d), по центру пилюля-навигация ссылками на основной сайт (Home → https://overdone.it/, Recruiting, Pricing), справа `nav.contact` (ghost, скролл к форме) и `nav.book_call` (primary, Calendly)
- Позиция: absolute поверх hero, при скролле вниз скрывается, при скролле вверх появляется фиксированной с фоном `rgba(7,7,7,0.8)` + blur 12px, бордер снизу `--color-border` (никаких теней)
- Mobile: лого + бургер → полноэкранное меню (фон bg, крупные пункты, внизу кнопки Contact/Book a call и переключатель языка)

Контент: CONTENT_SOURCE «Проєкти…» + ключи `projects.*` из ADDITIONS. Визуально НЕ повторяет аккордеон главной.
- Данные — массив в компоненте:
```js
const partners = [
  { id: 'paparazzi', name: 'Paparazzi', descKey: 'projects.paparazzi_desc',
    url: 'https://paparazzi.shop', caseUrl: null, // TODO: страница кейса, v2
```

- Кнопки карточки: primary-ghost `projects.visit` (→ url, новая вкладка), secondary `projects.case` — если `caseUrl === null`, кнопка disabled с подписью `projects.case_soon` (small muted). `@click.prevent.stop`
- Скриншоты: заглушка `partner-placeholder.webp` (градиент surface→bg + крупный логотип-текст) с TODO(ASSET); заказчик положит реальные скрины paparazzi.shop в /public/img/partners/
- Последняя карточка — «Ваш продукт може бути наступним»: та же геометрия, вместо скриншота пунктирная рамка с большим `+` и свечением, кнопка primary `cta.discuss` → #contact
- Mobile: карточки в столбик, окно скриншота сверху

## §5. «Сайт — лише видима частина» (SectionLayers) — флагманская scroll-секция

Контент: CONTENT_SOURCE, ключи `layers.*` (подписи слоёв в ADDITIONS §2). Референс: «фото 5» пользователя + neoconda — раскрытие одного элемента на слои.
- Идея: стилизованный интерфейс интернет-магазина (упрощённый SVG-мокап: шапка, карточка товара, кнопка «Купити») при скролле раскладывается на 6 слоёв в изометрии/перспективе, под ним проявляются слои: CRM → Оплата → Склад → Доставка → Повідомлення → Аналітика. Каждый слой — плоскость (surface, бордер, лёгкий glow) с mono-подписью и короткой строкой, соединены тонкими вертикальными линиями
- Механика: секция pin на ~2.5 высоты вьюпорта, scrub. Таймлайн: (1) мокап целиком + заголовок и первый абзац слева; (2) наклон в перспективу (rotateX ~55deg, CSS 3D), слои разъезжаются по Y/Z с stagger, подписи fade-in по одному; (3) абзац «Якщо ці процеси не пов’язані…» сменяется выводом «Тому ми створюємо єдину систему…» (акцентная строка), слои подсвечиваются связующими линиями красным
- Layout: слева sticky-текст (заголовок, абзацы по фазам), справа сцена со слоями. Слои — HTML/SVG с transform, не canvas
- Mobile / reduced-motion: без pin — статичная «взорванная» изометрия (готовое конечное состояние) сверху, текст под ней целиком
- Производительность: transform-only, will-change на слоях на время анимации

## §7. Сравнение моделей (SectionCompare) — новый блок

Контент: CONTENT_ADDITIONS §3, ключи `compare.*`. По решению заказчика — **два блока один под другим**, не таблица в две колонки.
- Заголовок секции + eyebrow `○ TWO MODELS`

## §8. «Розробка без початкового бюджету» (SectionModel)

Контент: CONTENT_SOURCE, ключи `model.*`.
- Две колонки: слева текст секции; справа — анимированный SVG-график «доход появляется с продажами»: ось времени, отметка «Запуск» (mono), до неё линия оплаты = 0 (плоская, muted), после — линия продаж растёт (белая) и вместе с ней линия нашего процента (красная, тоньше). Линии отрисовываются stroke-dashoffset при попадании в вьюпорт (1.2s, power2.inOut), подписи fade

## §9. «Що ми беремо на себе» (SectionScope)

Контент: CONTENT_SOURCE — 7 пунктов, ключи `scope.*`.

## §10. «Як починається партнерство» (SectionSteps) — вторая scroll-секция

Контент: CONTENT_SOURCE — 5 шагов, ключи `steps.*`. Референс: sstr.tech (объяснение по скроллу).
- Desktop: pin на ~2 вьюпорта. Слева sticky: огромный номер шага (`$fs-number`, контурный/muted, при активации заливается красным counter-морфом 01→05) + заголовок шага; справа скроллятся описания, активное — белое, остальные opacity 0.35. Прогресс — тонкая вертикальная линия с красным заполнением по scrub

- Mobile / reduced-motion: обычная вертикальная timeline: линия слева, номера-точки, все шаги раскрыты
- Внутри шага 04 есть второй абзац про сроки — не терять

## §11. Калькулятор условий (SectionCalc)

Контент: CONTENT_SOURCE «Умови розраховуються індивідуально» + CONTENT_ADDITIONS §4 (`calc.*`). Идея заказчика: вовлекающий мини-калькулятор с ползунками вместо сухого списка из 9 факторов.
- Layout: слева заголовок + вводный текст + 9 факторов компактными mono-чипами (muted; 4 из них соответствуют ползункам и подсвечиваются при их движении); справа карточка калькулятора (surface, glow-бордер)
- Ползунки (PSlider, кастомный: трек 2px, ручка 20px белая с красным ободом при drag, значения snap по шагам): 1) маржинальность — 4 ступени `calc.margin_*`; 2) объём онлайн-продаж/мес — 5 ступеней `calc.volume_*`; 3) средний чек — 4 ступени; 4) количество интеграций — 1–10
- Результат: крупно «`calc.result_label`: X–Y%» — диапазон 2 п.п. Число меняется каунтером 300ms. Формула — простая прозрачная эвристика в коде с комментарием TODO(FAKE): база 6%; высокая маржа +1…2; большой объём −1…2; высокий чек −0.5…1; много интеграций +0.5…1.5; clamp 2–12%, диапазон = [round(x−1), round(x+1)]
- Под результатом обязательный дисклеймер `calc.disclaimer` (small, muted) — это не оферта, финальный процент после анализа. Дисклеймер не скрывать и не уменьшать ниже 12px
- Финальный абзац секции («До початку роботи обидві сторони розуміють…») под всем блоком
- Доступность: ползунки — `input type="range"` со стилизацией, label + aria-valuetext со строковым значением ступени

Контент: CONTENT_SOURCE, ключи `align.*`. Референс: daoism.systems «network of trust» — перелистывающиеся карточки.

- Замыкающий абзац «Це робить наші відносини…» — body-lg
- Reduced-motion: карточки сеткой 2×2 без перелистывания

## §14. Финальный CTA + форма (SectionContact, id="contact")

Контент: CONTENT_SOURCE финальный блок + CONTENT_ADDITIONS §6 (`form.*`). Принцип — как форма «Get in Touch» на главной (минимализм, нижние бордеры), но полей больше и добавлены табы. Фоном — красное свечение снизу (как футер главной с 3D-фигурой; слот TODO(ASSET))
- Слева: заголовок, два абзаца, ниже кнопка `cta.telegram` (secondary) — Telegram как равноценный канал
- Справа форма:
  - Табы (пилюли, 2 шт.): `form.tab_has` «Вже є магазин» / `form.tab_no` «Магазину ще немає». Переключение — slide подчёркивания, поля меняются с fade 200ms без прыжка высоты (min-height по большему табу)
  - Общие поля: Ім’я* (text), Компанія (text), Контакт* (text, hint `form.contact_hint`: «телефон, Telegram, email або посилання — будь-який зручний спосіб»)
  - Таб «є магазин»: Посилання на магазин/продукт* (url, мягкая валидация), Що ви продаєте (text), Обсяг онлайн-продажів/міс — PSlider 5 ступеней `form.volume_*`, Як обробляються замовлення — чипы-мультивыбор `form.orders_*` (Вручну / CRM / Таблиці / Інше)
  - Таб «немає»: Що плануєте продавати* (text), Де продаєте зараз — чипы `form.channels_*` (Instagram/соцмережі, Маркетплейси, Офлайн, Ще не продаємо), Очікуваний обсяг — тот же PSlider (необязателен)
  - Submit primary `cta.discuss` на всю ширину; loading-спиннер; mock-отправка 800ms → success-состояние вместо формы: `form.success_title` + `form.success_text` + кнопка Telegram. TODO(API)
  - Валидация on-blur + on-submit, тексты `form.err_*`, ошибка под полем, поле краснеет бордером `--color-error`
- Слайдер объёма здесь и в калькуляторе — один компонент PSlider
