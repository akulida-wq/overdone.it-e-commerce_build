# DESIGN — визуальная система

Источник: действующий сайт overdone.it + макет Figma «\<OD\> Overdone.it» (главная, 1400).
Страница партнёрства должна выглядеть как родная часть этого сайта, но блоки внутри — новые (не копировать секции главной один в один).

## 1. Цвета (значения из Figma-макета)

```scss
// _theme.scss
:root {
  --color-bg:            #070707;  // фон страницы (background_dark)
  --color-surface:       #151515;  // карточки, панели (background)
  --color-surface-2:     #1d1d1d;  // hover-состояние поверхностей
  --color-accent:        #F12625;  // красный акцент (Red)
  --color-accent-hover:  #ff3b3a;
  --color-text:          #ffffff;
  --color-text-secondary:#a7a7a7;  // secondary
  --color-text-muted:    #7a7a7a;  // Grey / подписи
  --color-border:        rgba(255,255,255,0.05); // #ffffff0d из макета
  --color-border-strong: rgba(255,255,255,0.12);
  --color-glow:          rgba(241,38,37,0.35);   // свечение акцента на тёмном
  --color-error:         #F6762E;
  --color-success:       #B0D356;
}
```

Правила:
- Красный — дозированно: акцентное слово в заголовке, primary-кнопки, номера/маркеры, свечения. Не заливать красным большие площади (исключение — панель «Your project next» стиля главной, если понадобится)
- Свечение (референс sharplink.com): мягкий radial-gradient `--color-glow` за ключевыми элементами, blur 80–120px, opacity ≤ 0.5

## 2. Типографика

Из макета: **SF Pro Display** (основной) + **IBM Plex Mono** (тех-подписи).

- SF Pro Display: заголовки и текст, letter-spacing −3% на крупных кеглях, line-height ~100% на заголовках. ВНИМАНИЕ: перед интеграцией разработчик должен проверить, каким файлом шрифт подключён на проде overdone.it, и взять его. Для локальной сборки — переменная `$font-display`; если файла SF Pro нет, временно Inter (ближайшая свободная замена), замена в одном месте
- IBM Plex Mono 400 (Google Fonts, subset latin+cyrillic) — eyebrow-ярлыки, номера, мелкие тех-подписи. Паттерн ярлыка как на главной: `○ LABEL` в верхнем регистре

Шкала (desktop → mobile):

| Токен | Размер | Использование |
|---|---|---|
| `$fs-h1` | 76px / 42px | H1 hero, lh 1.0, ls −3% |
| `$fs-h2` | 48px / 32px | заголовки секций, lh 1.05, ls −2% |
| `$fs-h3` | 28px / 22px | подзаголовки, карточки |
| `$fs-body-lg` | 20px / 18px | лид-абзацы, lh 1.4 |
| `$fs-body` | 16px | основной текст, lh 1.5 |
| `$fs-small` | 14px | подписи, форма |
| `$fs-mono` | 14px / 12px | IBM Plex Mono, ярлыки |
| `$fs-number` | 96px / 56px | декоративные номера шагов 01–07, цвет muted или обводка |

Заголовки секций: белый текст + одно-два акцентных слова красным (`SectionTitle` принимает строку с маркером, напр. `"Сайт — лише [видима частина]"` → слова в скобках красные). Карта акцентов — в PAGE_SPEC у каждой секции.

## 3. Сетка и отступы

- Макет 1400. Контейнер: max-width 1360px, боковые поля 64px (desktop) / 24px (mobile)
- Вертикальный ритм секций: 140px desktop / 80px mobile между секциями
- Шкала: `$spacing-1: 4px` … `$spacing-16: 128px` (кратно 4/8)
- Радиусы: `$radius-sm: 8px`, `$radius-md: 16px`, `$radius-lg: 24px` (карточки), `$radius-pill: 999px` (кнопки)
- Breakpoints: 1280 / 1024 / 768 / 480

## 4. Базовые компоненты

**PButton** — пилюля, как на главной:
- `primary`: фон `--color-accent`, белый текст, иконка-стрелка в круге справа; hover — `accent-hover` + лёгкое свечение; active — scale 0.98
- `secondary`: прозрачный, бордер `--color-border-strong`, белый текст; hover — фон `--color-surface`
- `ghost`: только текст + стрелка
- Высота 44–48px (тач-таргет ≥44), паддинги 20–24px, mono или display 14–16px

**SectionEyebrow** — `○ LABEL` mono, muted, 14px, letter-spacing +2%, upper-case.

**Карточки** — фон `--color-surface`, бордер 1px `--color-border`, radius `$radius-lg`; hover: бордер strong + лёгкий подъём (translateY −4px, 200ms) или свечение. Никаких box-shadow-«материала» — только бордеры и glow.

**Инпуты** — как форма на главной: прозрачный фон, нижний бордер 1px `--color-border-strong`, label над полем (small, muted), focus — бордер белый, при ошибке `--color-error` + текст ошибки 12px под полем.

**Аккордеон (FAQ)** — строка с бордером снизу, плюс/крест справа (поворот 45° при открытии, 250ms), раскрытие높 height через grid-rows trick или GSAP, 300ms ease.

## 5. Иконки и графика

- SVG stroke 1.5px, скруглённые концы, один стиль на всю страницу. Размеры токенами: 20/24/32
- 3D-красные глянцевые формы (как в hero главной) мы сгенерить не можем: в hero заложить слот под ассет `public/img/hero-3d.webp` + временный фолбэк — большое мягкое красное свечение + абстрактная SVG-фигура. TODO(ASSET) в коде
- Пунктирная карта мира с главной НЕ используется (не дублируем главную)

## 6. Моушен

Плавный скролл: Lenis (lerp ~0.1). GSAP + ScrollTrigger.

Принципы:
- Микро-взаимодействия 150–300ms, `power2.out`
- Появление блоков: fade + translateY 24px, stagger 60–90ms, триггер при 80% вьюпорта, один раз (без реверса при скролле вверх)
- Scroll-driven секции (pin + scrub): максимум две на страницу — «видимая часть» (§5 спеки) и «как начинается партнёрство» (§10). Остальное — простые reveal, иначе страница станет утомительной
- Ticker — бесконечный marquee как на главной, пауза при hover, duration ~30s
- Hover карточек/кнопок обязателен на desktop, но ни одно взаимодействие не должно быть доступно ТОЛЬКО по hover
- `prefers-reduced-motion: reduce` → отключить Lenis, pin, marquee (статичная строка), оставить мгновенные состояния
- Не анимировать width/height/top/left — только transform/opacity. Следить за CLS
