# Overdone — E-commerce Partnership Landing: пакет для Claude Code

Что здесь:

```
CLAUDE.md                  — правила проекта (кладётся в корень репозитория)
docs/CONTEXT.md            — что за услуга и зачем страница
docs/DESIGN.md             — визуальная система (токены из Figma, шрифты, моушен)
docs/PAGE_SPEC.md          — спецификация всех секций §0–§15
docs/CONTENT_SOURCE.md     — исходный текст UA/EN (не редактировать)
docs/CONTENT_ADDITIONS.md  — тексты новых блоков и UI-строки (черновик — вычитай)
prompts/PROMPT_1..7.md     — поэтапные промты
prompts/REVISIONS.md       — схема правок после сборки
```

## Как запускать

1. Создай пустую папку проекта, положи туда CLAUDE.md, docs/ и prompts/
2. Перед стартом вычитай `docs/CONTENT_ADDITIONS.md` — это мои тексты под твою доку (тикер, сравнение, калькулятор, форма). Правь прямо в файле
3. Прогоняй промты по порядку 1 → 7, каждый — отдельной сессией/задачей. Этапы 1, 3, 5 — Opus (каркас и сложные scroll-секции), 2, 4, 6, 7 можно Sonnet
4. После каждого этапа смотри результат глазами. Мелкое правь сразу follow-up сообщением в той же сессии, крупное — копи на круг правок по REVISIONS.md
